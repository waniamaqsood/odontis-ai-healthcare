# 🦷 Odontis AI Healthcare Platform

AI-Powered Dental Healthcare Platform using CNNs, Flask, React, and Botpress

---

## 🧠 Intro

Odontis is an AI-powered dental healthcare platform that integrates Convolutional Neural Networks (CNNs) with a modern web application to assist in dental image analysis and healthcare support.

The project combines AI model development, conversational AI, and full stack web technologies to create an interactive and accessible healthcare experience.

## ✨ Features

Users can:

- Upload dental-related images
- Receive AI-assisted analysis using CNN models
- Interact with a Botpress-powered healthcare chatbot
- Navigate a responsive healthcare interface
- English to Urdu translation support for better accessibility and local user experience
- Access healthcare-related support features
- Use the application across desktop and mobile devices

Developer Features:

- CNN-based image classification
- AI model integration with Flask APIs
- Conversational AI integration using Botpress
- Real-time frontend and backend communication

---

## 🏗️ The Process

The project began with researching how AI could assist healthcare workflows, particularly through image analysis using Convolutional Neural Networks (CNNs).

The CNN model was developed and trained in Python for image classification tasks. After experimenting with preprocessing techniques and model architecture, the AI functionality was integrated into a Flask backend.

To improve user interaction and accessibility, a Botpress chatbot was integrated into the platform to provide conversational healthcare assistance and guide users through the application.

React was used to build a responsive frontend interface that communicates with backend APIs and displays AI-generated results in an interactive way.

## ▶️ How to Run This Project

### Clone the Repository
```bash
git clone https://github.com/waniamaqsood/odontis-ai-healthcare.git
```

### Frontend Setup
```bash
cd frontend
npm install
npm run dev
```

### Backend Setup
```bash
cd backend
pip install -r requirements.txt
python app.py
```
